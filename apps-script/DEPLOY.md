# استقرار نسخه Google Drive-only برای مرکز ۶۳۶ خفر

این نسخه قرارداد ذخیره‌سازی را یکسان می‌کند:

- پرونده‌ها، نامه‌ها، پیگیری‌ها، کروکی‌ها و تنظیمات در فایل اصلی `Nezam636_Master_DB.json` داخل Google Drive ذخیره می‌شوند.
- پیوست هر پرونده مستقیماً با API مدارک در پوشه همان پرونده در Google Drive بارگذاری، فهرست، دریافت و حذف می‌شود.
- فیلد قدیمی `indexedDBDocs` دیگر برای ذخیره نسخه اصلی اجباری نیست. اگر در فایل‌های قدیمی موجود باشد، هنگام دریافت از پاسخ API حذف می‌شود.
- کنترل اعتبار آرایه پرونده‌ها، نامه‌ها و فهرست حذف دائمی و کنترل تعارض نسخه همچنان فعال است.

## مرحله ضروری: به‌روزرسانی Web App موجود

کد مخزن GitHub Pages به‌تنهایی نمی‌تواند نسخه منتشرشده Google Apps Script را تغییر دهد. برای اینکه خطای فعلی کاملاً برطرف شود، کد سمت سرور نیز باید در همان پروژه‌ای که URL فعلی Web App را ارائه می‌کند منتشر شود.

1. در GitHub فایل `apps-script/Code.gs` را باز کنید و محتوای کامل آن را کپی کنید؛ یا فایل Code.gs اصلاح‌شده‌ای را که همراه این اصلاح آماده شده جایگزین کنید.
2. پروژه Google Apps Script متصل به Web App فعلی را باز کنید. همان پروژه‌ای باشد که URL آن در `index.html` تنظیم شده است؛ پروژه جدید نسازید.
3. فایل `Code.gs` همان پروژه را به‌طور کامل با نسخه جدید جایگزین و ذخیره کنید. فایل‌های دیگر پروژه را حذف نکنید.
4. مقادیر موجود در **Project Settings → Script Properties**، به‌ویژه `NEZAM636_ALLOWED_EMAILS`، را حفظ کنید. مجوزها و تنظیمات Drive را تغییر ندهید.
5. به **Deploy → Manage deployments** بروید. Web App موجود را با دکمه ویرایش باز کنید، در قسمت Version گزینه **New version** را انتخاب و Deploy کنید. تنظیمات اجرای برنامه و دسترسی را همانند انتشار قبلی نگه دارید تا URL فعلی عوض نشود.
6. پس از تکمیل انتشار، سایت GitHub Pages را باز کنید و `Ctrl + F5` بزنید. با همان روش OTP وارد شوید.
7. ابتدا «بازخوانی از درایو» را اجرا کنید. پس از مشاهده اطلاعات، یک تغییر آزمایشی بی‌خطر انجام دهید و ذخیره را بزنید. فقط وقتی پیام تأیید ذخیره و بازخوانی مجدد نمایش داده شد، همگام‌سازی تأیید شده است.

## نکته تشخیصی

اگر هنوز پیام «فهرست اسناد IndexedDB در نسخه ارسالی وجود ندارد» مشاهده شد، نسخه جدید `Code.gs` هنوز در Web App منتشر نشده یا پروژه اشتباهی ویرایش شده است. نسخه وب اکنون این خطای قدیمی را با راهنمای دقیق انتشار نمایش می‌دهد.

**هشدار:** برای آزمایش اولیه، پرونده یا پیوست واقعی را حذف یا جایگزین نکنید. ابتدا فقط بازخوانی و سپس یک تغییر بی‌خطر در داده آزمایشی را بررسی کنید.
